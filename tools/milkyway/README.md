# 銀河圖層產生工具

`build_milkyway.py` 產生 `sky/index.html` 裡的 `MW_DATA`（銀河圖層的亮度點位）。來源是歐洲南方天文台（ESO）公開的銀河全景照片，授權明確允許商業使用。2026-10-05 起取代原本來自 d3-celestial `mw.json` 的銀河輪廓；那份資料的原作者沒有聲明授權。

## 輸入檔

這個環境連不到 eso.org，所以用 GitHub 上一份可以核對來源的副本，網址固定在加入該檔的 commit：

- 網址：<https://raw.githubusercontent.com/typpo/spacekit/c90a496d2252702d13e1659101ce0d99b2bea0e5/src/assets/skybox/eso_milkyway.jpg>
- SHA-256：`9ed7908d233f98a814a52caba2e525b1849e14592cded3355be1611a8ef14ec7`，2,475,382 bytes，4096 × 2048 px（ESO 6000 × 3000 版本等比例縮小）
- 來源核對：
  - 檔案內嵌 ESO 的 AVM 中繼資料：`avm:ID` = eso0932a、`avm:ReferenceURL` = eso.org/public/images/eso0932a/、credit「ESO/S. Brunier」、標題「The Milky Way panorama」、日期 2009-09-14；說明文字與 ESO 網頁相同。
  - spacekit 的 `src/assets/skybox/README.md` 也註明這張圖來自 eso0932a。
  - spacekit 的程式碼是 MIT 授權，不影響這張圖仍屬 ESO 的授權。
- 腳本每次都會核對大小、SHA-256 與內嵌資訊。

也可以改用 ESO 官方檔：`--source eso`（Large JPEG，6000 × 3000），或先自行下載再用 `--image 路徑`。腳本會先縮成 4096 × 2048 再處理。用模擬的 6000 × 3000 檔測試時，3,388 點中約 60 點的等級差 1 級，其餘相同。

## 使用方式

```bash
pip install numpy scipy pillow          # Python 3.9 以上；scipy 1.6 以上
python3 tools/milkyway/build_milkyway.py --write    # 下載（存到 tools/milkyway/.cache/）、計算、寫回 sky/index.html
python3 tools/milkyway/build_milkyway.py --check    # 重新計算並和 index.html 現有資料比對；完全相同才回傳 0
python3 tools/milkyway/build_milkyway.py --compare-html 舊版index.html   # 另外輸出和舊資料的比較
```

輸出是 JSON 報告：方向校正結果、門檻、刪除的區塊與驗證數字。整個流程在 2 vCPU 的機器上約 20 秒，記憶體峰值約 200 MB。

## 做法

1. **方向校正**。照片是銀河座標的等距長方投影（中心是銀河中心、銀經往左增加），但和 IAU 銀河座標並不完全對齊。
   - 腳本在照片中找出星點，和 App 自己的星表（`STAR_DATA` 中 4.5 等以內的 909 顆）比對，擬合一個 3D 旋轉。
   - 結果：照片的座標框和銀河座標差 **3.78°**；照片中心其實落在銀經 −3.2°、銀緯 +1.7°。
   - 校正後配對到 752 顆，位置殘差中位數 0.065°、90% 在 0.115° 以內。
   - 不校正的話，煤袋、大暗隙等暗帶會偏移 3～4°。
2. **去除星點與背景**。用 0.8° 的中位數濾波去掉星點（App 另外畫恆星），再扣掉 |b| ≥ 40° 天區的背景中位數。
3. **平滑**。在球面上做高斯平滑，σ = 1.0°。格點間距是 1.37°，這樣既能避免取樣雜訊，又能保留 3～5° 寬的暗帶。
4. **取樣與分級**。
   - 取樣點用和舊資料完全相同的 20,000 點 Fibonacci 格點。
   - 依「各等級覆蓋的天空面積」切成 5 級，面積比例沿用舊資料（等級 ≥1～≥5：16.94%、4.21%、1.615%、0.445%、0.125%），所以渲染程式每一級的亮度設定不用改，整體亮度和以前相同，改變的只有形狀。
5. **只保留銀河盤面**。和銀緯 |b| < 5° 不相連的區塊全部刪除，共 8 塊、46 點：

   | 區塊 | 點數 | 為什麼刪 |
   |---|---|---|
   | 大麥哲倫雲 | 20 | 銀河系外的星系；App 的「星雲、星團、星系」圖層已標示 |
   | 小麥哲倫雲（含杜鵑座 47） | 5 | 同上 |
   | 照片中的一顆行星（赤經 349.6°、赤緯 −4.0°，黃緯 0.4°） | 5 | 拍攝當時剛好在那裡，不是固定天體 |
   | 昴宿星團 | 4 | 不屬於銀河光帶，星點另外畫 |
   | 加州星雲 NGC 1499 | 4 | 肉眼幾乎看不到 |
   | 仙女座星系 M31 | 3 | 銀河系外，DSO 圖層已標示 |
   | 獵戶座大星雲一帶 | 2＋3 | 不屬於銀河光帶，DSO 圖層已標示 |

   大、小麥哲倫雲是**刻意刪除**的：
   - 這個圖層的開關叫「銀河」，麥哲倫雲是另外的星系，DSO 圖層已經標示。
   - 舊資料也沒有麥哲倫雲，維持原本的外觀。
   - 台灣看不到它們。
6. 寫入 `index.html`。座標取到 0.1°（每個點畫成約 4° 寬的柔光，0.1° 的誤差看不出來），格式仍是 `[赤經, 赤緯, 等級, …]`（ICRS/J2000，度）。

## 驗證結果（2026-10-05）

| 指標 | 舊（Vieira 輪廓） | 新（ESO 照片） |
|---|---|---|
| 點數（等級 1/2/3/4/5） | 3,388（2546/519/234/64/25） | 3,388（2546/519/234/64/25） |
| 最亮一級的重心（銀經, 銀緯） | (+1.4°, −3.8°) | (−0.8°, −4.4°)，人馬座大恆星雲 |
| 銀河帶是否連續：每 1° 銀經在 \|b\| ≤ 10° 內都有點 | 缺 1 處（l = 143°） | 360° 全部連續 |
| 銀道（b = 0）上有點的比例 | 87.9% | 95.4%；缺口是大暗隙與煤袋等暗星雲 |
| 互相連通的區塊數 | 1 | 1 |
| 最大 \|b\| | 21.2° | 19.7° |
| `MW_DATA` 大小 | 50,881 bytes | 43,727 bytes |

**和舊資料的 IoU**（只是合理性檢查，舊資料不是標準答案）：

| 等級 | ≥1 | ≥2 | ≥3 | ≥4 | ≥5 |
|---|---|---|---|---|---|
| IoU | 0.765 | 0.482 | 0.398 | 0.521 | 0.667 |

**獨立交叉檢查**：拿 NASA SVS「Deep Star Maps」（SVS 3895，由星表畫成的全天圖）跑同樣流程。這張圖方向校正後殘差 0.03°。

| 比較 | ≥1 | ≥2 | ≥3 | ≥4 | ≥5 |
|---|---|---|---|---|---|
| 新資料 vs NASA 星圖 | 0.72 | 0.53 | 0.45 | 0.42 | 0.56 |
| 舊資料 vs NASA 星圖 | 0.68 | 0.45 | 0.33 | 0.39 | 0.43 |

每一級的 IoU 都比舊資料高，代表新資料和獨立資料更一致。

## 已知限制

- **煤袋**：在新資料中是亮帶裡下陷 1～2 級的暗區，不像舊的手繪輪廓那樣挖成空洞。照片裡的煤袋並不是全黑，依亮度分級時，它落在和冬季銀河差不多的等級。
- **冬季銀河**：較舊資料窄、也稍暗；照片中的冬季銀河本來就比夏季暗很多。
- **只用一張照片**：結果反映這張照片的影調處理。如果要調整觀感，請改參數區的常數，再用 `--write` 重新產生，不要手改 `MW_DATA`。
